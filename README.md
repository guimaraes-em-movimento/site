# Guimarães em Movimento — site

Site público da Associação Guimarães em Movimento.

**Estado:** em preparação.

## Como funciona

- Site estático, publicado no [Cloudflare Pages](https://pages.cloudflare.com/) com o domínio da associação.
- Cada alteração em `main` é publicada automaticamente.
- Os conteúdos (textos, notícias, atividades) vão ficar em Markdown, editáveis sem mexer em código.

## Regras

- Este repositório é público: não colocar aqui palavras-passe, chaves nem dados pessoais de sócios.
- Os dados de sócios e quotas ficam nas ferramentas internas da associação, nunca aqui.
